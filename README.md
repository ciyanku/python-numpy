## Repository Contents

* **Arrays.ipynb**

  * Creating NumPy arrays
  * Array attributes
  * Array data types
  * Basic array operations

* **array_operations.ipynb**

  * Arithmetic operations
  * Mathematical functions
  * Aggregation functions
  * Array manipulation

* **array_indexing.ipynb**

  * Indexing
  * Slicing
  * Boolean indexing
  * Fancy indexing

* **exersises.ipynb**

  * Practice questions
  * NumPy exercises
  * Problem-solving using arrays

This repository documents my journey of learning NumPy for Data Science, Machine Learning, and AI. The notebooks contain examples, experiments, and exercises that help build a strong foundation in numerical computing with Python.
